# 情境与动作差异：先做什么，再说什么

本页教如何让创意随使用情境变化，不定义生成几个版本或如何批量提交。数量、组合与执行安排由 Agent 根据用户任务决定；做单条日常 UGC 时也可以使用这里的方法。

以下是同款香水的三个独立 few-shot。按需要读取对应完整原文：`prompts/tennis-video.txt`、`prompts/car-video.txt`、`prompts/room-video.txt`。这些案例每条约 5 秒，展示一个生活动作片段，不各自重演完整开箱。更完整的需求与判断说明见 [案例索引](cases.md)。

| 网球场 | 低头翻包取瓶，抬眼分享 | 其实我一般运动会用这个香水，感觉蛮适合的。 | 白空顶帽、高马尾、黑运动服、运动表、场边长椅 |

这些是香水示例，不是必须出现的场景组合。先找到新商品在当前情境中的“使用时刻”，再设计人物动作与顺口的短句。用户需要多个创意时，比较它们是否真的体现了不同使用行为或叙事切口；数量由任务决定，不强行凑成三个。

## 从动作长出台词

1. 先确定手上干什么、物品原来在哪、最后放哪，视线追随这个动作。
2. 再写她当下可能顺口说的一句话。不要为每条制作广告金句；不要强编出门约会等背景故事。
3. 动作发生时可停说。喷雾、闻香和整理头发本身提供内容，保留环境声即可。
4. 静态参考不是必须的开场姿态。例如参考手持香水，开头可从包里取出，但必须写明瓶子最初在包中，不能双份出现。工具若只支持严格首帧则调整设计。
5. 不强制结尾举瓶微笑，片段可以在自然行动中结束。
6. 用户认可图后只改动作／台词，保留外貌、服饰、光线与镜头距离基线。修改任何其他项须说明。

以足够具体的动作顺序、自然台词和摄影关系写成完整提示词，供 Agent 按当前任务调用。不要把“背景／穿搭不同”自动当成创意已不同，也不用为了显得不同强编剧情。

若用户给了参考作者的多版本视频：先看原片实际改了什么，区分人物、场景、动作、对白与机位变化，再决定本次的变化维度；不凭简介或标题猜测。

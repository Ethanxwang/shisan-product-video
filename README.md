# 十三 · 商品视频工厂

一张产品图 + 一句话要求，做出自然 UGC／KOC 开箱试用视频，或实拍感产品概念片。

这是给 AI Agent 用的 Skill：内置创作方法、完整导演提示词和已认可案例。Agent 负责理解需求、安排生成；Skill 负责专业判断与 few-shot 示范。

## 能做什么

| 你想做什么 | Skill 提供 |
| --- | --- |
| 真人分享、开箱、日常试用 | 自然 UGC 方法 + 完整提示词示范 |
| 同一商品多种使用情境 | 情境与动作差异方法（先动作，再台词） |
| 产品概念展示 | 实拍实验概念片方法 + 提示词 |

## 快速上手

把本仓库作为 Skill 导入你使用的 Agent／创作平台，上传商品图后说：

> 帮我做一条真人分享感的开箱视频。

> 同一款商品做三个短版本，人物、场景、穿搭和使用动作都不同，先给我动作与台词。

> 做一条超酷的实拍实验概念展示片，不要高奢慢推。

## 仓库结构

```
SKILL.md                 # Skill 入口与职责
assets/                  # 案例人物图／产品图（复现基线用）
references/
  ugc.md                 # 自然 UGC 方法（含换商品判断）
  concept.md             # 概念片方法
  variations.md          # 情境与动作差异
  cases.md               # few-shot 案例索引
  prompts/               # 完整生图／视频提示词原文
```

## 使用原则

- **正常任务用你的商品图**，不要把示例香水当成你的产品。
- **换商品时学判断方法**，不照搬香水动作与台词；详见 `references/ugc.md`。
- **精确复现案例**时，才使用 `assets/` 里的图片 + `prompts/` 完整原文。
- 默认 720p、9:16；模型与费用以你当前平台的选择为准。
